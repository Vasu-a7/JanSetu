# JanSetu — Connecting Citizens and Administration

Created for Smart India Hackathon 2026 (Problem ID SIH26043), JanSetu is a central platform that connects citizens, the government, universities, and businesses to solve local public problems quickly and smartly.

## Key Features
- **AI Description Enhancer**: Instant Gemini AI report structuring with editable Hindi/English/Hinglish inputs.
- **University Capstone Innovation Hub**: Triple-Helix collaboration for academic research labs to adopt civic problems.
- **Student Volunteer Field Audits**: Ground verification with certified NSS volunteer credit logs and digital certificates.
- **District Analytics & Kanban Board**: Government management workspace with role-based status updating.
- **Supabase Backend Integration**: Cloud database persistence for reports, capstones, verifications, and user profiles.
